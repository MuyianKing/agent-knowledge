# CURD 实现参考

本文档记录实现通用前端 CURD 页面时应关注的结构和行为。具体框架、组件库、目录、文件名和 API 以目标项目现有规范为准。

## 先读取项目上下文

实现前先确认：

- 项目规则和编码规范
- 页面、组件、服务、模型的目录约定
- 现有 CURD 页面
- 请求封装和错误处理
- 表格、查询、表单、弹窗和消息组件
- 路由和菜单入口
- 可用的字典、枚举、上传和远程选择组件
- 格式检查、构建和测试命令

已有页面是最重要的实现参考。优先复用项目现成模式，不要按个人习惯新建第二套 CURD 架构。

## 字段清单

先将接口字段分成三类：

- 查询字段：用于筛选列表
- 列表字段：用于表格展示
- 表单字段：用于新增和编辑

为每个字段整理以下信息：

- 字段名
- 显示名称
- 类型
- 是否必填
- 默认值
- 枚举和字典
- 校验规则
- 查询方式
- 列表展示方式
- 新增和编辑时是否可修改
- 是否依赖其他字段

接口返回字段不等于必须全部展示，也不等于必须全部放入表单。

## 页面职责

列表页面通常负责：

- 持有查询条件
- 调用分页查询
- 配置列表列
- 打开新增/编辑表单
- 执行删除和其他行操作
- 在操作成功后刷新数据

编辑表单通常负责：

- 初始化新增数据
- 回显编辑数据
- 控制字段和控件
- 执行表单校验
- 提交表单数据
- 关闭弹窗并通知页面刷新

接口服务通常负责：

- 列表查询
- 新增
- 编辑
- 删除
- 必要的参数转换
- 统一的请求错误处理

数据模型通常负责：

- 表单字段初始化
- 类型合理的默认值
- 编辑数据回显
- 不让未定义字段直接进入表单

## 查询区域

查询配置应直接映射接口查询参数。常见控件包括：

- 文本输入
- 数字输入
- 下拉选择
- 单选或多选
- 日期或日期范围
- 远程搜索
- 树形或级联选择

枚举选项、值类型和空值行为必须以接口文档或项目字典为准。数字查询要确认前端是否需要显式转换为 number；日期查询要确认接口需要字符串、时间戳还是范围数组。

## 列表区域

普通列使用表格组件的列配置。需要特殊展示时，优先使用项目表格组件提供的能力：

- 列插槽
- 表头插槽
- 渲染函数
- 自定义列组件
- 操作列

常见自定义场景：

- 枚举值转换为可读文本
- 状态显示为标签、开关或图标
- 日期、金额、百分比格式化
- 图片、头像、链接
- 多字段组合展示
- 树形名称和层级缩进
- 行级编辑、删除、详情、复制、添加子项

自定义展示不应破坏接口原始字段。除非项目已有数据转换约定，否则将转换限制在列表渲染边界。

## 表单区域

普通字段使用项目表单配置。根据已有组件能力选择：

- 输入框
- 数字输入
- 下拉框
- 单选或多选
- 日期选择
- 上传
- 远程选择
- 树形选择
- 级联选择

自定义字段时按以下优先级处理：

1. 使用现有表单组件配置
2. 使用字段级插槽或渲染函数替换内部控件
3. 使用自定义表单项控制标签、校验和控件
4. 多个页面重复需要时，再扩展通用表单组件

自定义控件必须绑定统一表单对象，并确保新增初始化、编辑回显、校验和提交行为与普通字段一致。

## 默认值

默认值优先级：

1. 接口文档明确的默认值
2. 项目已有业务约定
3. 用户明确确认的规则
4. 字段类型和空值约束的技术兜底

一般类型可参考：

- 字符串：空字符串或接口指定值
- 数字：接口指定值、零或空值，取决于是否允许为空
- 布尔值：接口指定的启用状态
- 数组：空数组
- 对象：空对象
- 枚举：接口允许的枚举值

状态、类型、父级标识、排序和权限字段不能只按字段名猜默认值。

## 字段联动

如果字段 B 是否显示、是否必填或可选项依赖字段 A，需要同时实现：

- B 的显示/隐藏
- B 隐藏时的校验处理
- A 切换后的 B 值清理
- 提交时对 B 的过滤或转换
- 新增和编辑时的初始显示状态

不能只做视觉隐藏而继续提交失效字段。例如类型切换后，某些只属于特定类型的路由、组件、权限或关联字段，应按接口约定清空或移除。

如果项目的通用表单组件不支持响应式显示配置，应使用现有插槽、条件渲染或项目推荐的表单扩展方式，不要擅自修改通用包。

## 接口服务

保存服务必须：

- 接收表单对象
- 按接口约定区分新增和编辑
- 在服务边界做字段转换
- 返回项目请求封装的 Promise
- 让表单提交流程能够等待成功或失败

新增和编辑可能是：

- 共用一个接口，通过标识字段区分
- 两个不同接口
- 同一路径但不同请求方式
- 需要不同的请求体结构

必须以文档为准，不能默认“有 id 就编辑”。删除接口也要确认是路径参数、查询参数、请求体还是批量数组。

## 树形和远程数据

遇到树形、级联、远程选项、关联数据或非标准分页时，先确认：

- 接口返回平铺还是树形数据
- 父级字段和根节点值
- 选项列表是否需要单独接口
- 编辑时如何回显选中项
- 是否需要排除当前节点和子节点
- 删除父节点时子节点的后端行为
- 表格组件是否真的支持树形展开

不要只根据字段名推测数据结构和组件能力。

## 完成检查

至少检查以下流程：

- 初次加载列表
- 查询条件提交和重置
- 列表分页
- 列表自定义展示
- 新增默认值
- 编辑回显
- 表单校验
- 自定义控件写回表单
- 字段联动和无效值清理
- 保存成功和失败
- 删除成功和失败
- 操作成功后的列表刷新
- 目标项目的 lint、构建和测试命令
